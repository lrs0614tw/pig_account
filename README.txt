毛豬結算

電腦需要 Windows、Python 3.10 以上，以及桌面版 Excel、Word。

第一次使用：完整解壓縮 → 雙擊「安裝環境.bat」（需連網）。
平常使用：雙擊「啟動毛豬結算.bat」。
請完整解壓縮後再執行，不要直接從 ZIP 裡開啟 BAT。
啟動優先使用 .venv；若沒有，會尋找已裝好套件的 Python。失敗訊息會記錄在 logs 資料夾。
結案前：先關閉要寫入的月份 Excel。

月份帳本放在「exports」直下；帳本備份放在「exports／backup」。
Word 放在「exports／出帳日（民國日期）」；草稿放在「毛豬結算／drafts」。
「預覽價款明細表」可先看 Word，不會結案或寫入 Excel。
「預覽開支請示／手續費」可先看開支單及對應市場的手續費單。
「預覽各項費用明細」每筆豬單一頁，運銷日期用拍賣日，填表日期用出帳日。
分享時不用附上 .venv；朋友應自行執行安裝環境。
若不想分享現有帳務，請在分享用副本移除草稿、月份帳本及備份，保留 templates。

月份帳本第一頁是月報表：自動累計當月頭數、豬款總價款、農會手續費。
Git 只更新程式與範本；exports、drafts、backup、月份帳本不納入版本控制。

預覽使用唯讀暫存 Word 文件，不會存入 exports；確認結案才保存正式文件。關閉預覽後，結算程式仍開啟時會自動清理暫存檔。

批次只填結帳／出帳日；拍賣日期在每筆豬單各自填寫。日期限定民國 yyy-mm-dd，例如 115-11-03。
月份帳本、月報及正式文件資料夾均依出帳日歸檔，不依拍賣日。

「匯入測試草稿」可載入 samples 裡的 5 組假資料；詳細情境見 samples／README.txt。
